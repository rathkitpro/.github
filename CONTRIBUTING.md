# Contributing to the rathkitpro organization

This repository holds the organization profile and community files, not product code.

Rathkit Pro paid packages do not accept outside code contributions. If you find a problem in one,
tell us at <hello@rathkit.com>. For security problems, follow the
[security policy](https://github.com/rathkit/.github/blob/main/SECURITY.md) and do not open an issue.

Changes to this repository follow the same rules as every Rathkit repository:

- Read the [Code of Conduct](CODE_OF_CONDUCT.md) and the [AI policy](AI_POLICY.md).
- Work from a fork. Do not push branches to this repository.
- Sign every commit with a verified GPG key and add a DCO sign-off (`git commit -s`, see
  [DCO](DCO)).
- Write commit messages as `type(scope): subject` (Conventional Commits), in American English,
  with no AI trailers.

Questions: [Discord](https://discord.gg/A5VBxgPaex).
